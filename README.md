# Laptop Power Bank (EDC Term Project)

## Project Overview

This project demonstrates the design and implementation of an emergency power bank for Dell/HP laptops using basic concepts of Electronic Devices and Circuits (EDC).

The system uses lithium battery cells connected in series and parallel to produce the required voltage and current to charge a laptop through an inverter.

---

## Objectives

• Design a portable emergency power bank
• Provide approximately **20V and 6A output** for laptop charging
• Apply concepts of **series and parallel battery connections**
• Understand DC-AC conversion using an inverter

---

## Components Used

| Component     | Description              |
| ------------- | ------------------------ |
| Battery Cells | 3–4V lithium cells       |
| Inverter      | Converts DC to AC        |
| Switch        | Power ON/OFF control     |
| DC Pin        | Charging input           |
| Box           | Protection and packaging |

---

## Battery Configuration

Each battery cell produces approximately **3–4 volts**.

To obtain higher voltage:

• **4 cells connected in series** to increase voltage
• Another **4-cell series pack connected in parallel** to increase current

This configuration provides approximately:

Voltage ≈ **16–20V**

---

## System Working

1. The battery cells are first charged using a DC charger.
2. The stored DC power from the batteries is sent to the inverter.
3. The inverter converts **DC voltage into AC voltage**.
4. The laptop charger is connected to the inverter output.
5. The charger then powers and charges the laptop.

The inverter produces approximately:

• **250V AC output**
• **Frequency ≈ 50 Hz**
